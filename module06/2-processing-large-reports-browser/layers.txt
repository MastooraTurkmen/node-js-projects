N-tier - folder structure

worker
  - all heavy CPU processing that might block the screen
    - Machine Learning processing
    - Data processing
    - for loops, crypto
    - also can call the service layer to process business rules!
service
  - all external APIs database connections, everything that goes online (outside)
  - all business rules
view
  - all iteration with the DOM. The only one that can change interface
controller
  - intermediates the communication between rules (services layer, or workers layer, if available)
   and presentation (views)
index.js
  - it is who can import modules
  - create instances and calls the "initialize" function
  - it is the startup!
